# Praktické cvičení 1: Základy Gitu a první odevzdání

Toto cvičení je zaměřeno na seznámení se s pracovním postupem v Gitu a GitHubu.

> [!IMPORTANT]
>
> 1. **Postupujte přesně podle pokynů.** Nesprávně odeslaný Pull Request (PR) bude zamítnut a budete muset vytvořit nový.
> 2. **ZÁKAZ PRÁCE V HLAVNÍ VĚTVI (`main`).** Pro každou novou práci/úkol si vždy vytvořte novou větev. Pokusy o přímý commit do `main` budou blokovány.

## Zadání

6. Založte si GitHub účet, ideálně s **univerzitním mailem**.
7. Nechte se pozvat do organizace/repozitáře `misavojte/KGI-PRODA-2026`.
8. Naklonujte si GitHub repozitář `misavojte/KGI-PRODA-2026` do svého počítače.
9. Vytvořte vlastní větev se jménem `vaseprijmeni/cviceni1`.
10. Ve složce `cviceni1` vytvořte složku `vaseprijmeni` a vložte do ní `geojson` soubor z předcházejícího bloku.
11. Vytvořte Pull Request do větve `main`.

### Výstup

- Pull Request do repozitáře `misavojte/KGI-PRODA-2026` obsahující:
  - Váš `geojson` soubor umístěný ve správné cestě: `/cviceni1/vaseprijmeni/soubor.geojson`.
