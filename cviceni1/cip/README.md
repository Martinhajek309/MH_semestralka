Instrukce pro vygenerování mapy s 2 body v Olomouci

- Nainstalujte závislosti:

```powershell
pip install -r requirements.txt
```

- Spusťte skript, který vytvoří `points.geojson` a `map.html`:

```powershell
python generate_map.py
```

- Otevřete `map.html` v prohlížeči (např. dvojklikem nebo `start map.html` v PowerShellu).
